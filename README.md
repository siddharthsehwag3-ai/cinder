# Cinder

**Write it. Run it. Understand it.**

Cinder is an interactive C-subset compiler and bounded virtual machine written from scratch in C. It runs natively from the command line and in the browser through WebAssembly.

Visitors can write a program, execute it, inspect compiler diagnostics, and explore the tokens, syntax tree, functions, and generated bytecode.

## Highlights

- Compiler core written in C
- Handwritten lexer
- Recursive-descent parser
- Abstract syntax tree
- Stack-based bytecode
- Bounded virtual machine
- Native command-line build
- WebAssembly browser build
- Background compilation with a Web Worker
- Source-linked diagnostics
- Interactive token explorer
- Interactive syntax-tree explorer
- Generated-instruction explorer
- Responsive interface
- Automated build, tests, and GitHub Pages deployment

## Language support

Cinder currently supports:

- Signed 32-bit integer values
- Basic `char` declarations and character literals
- Local variables
- Nested block scopes
- Arithmetic operators
- Comparisons
- Short-circuit logical expressions
- Bitwise operators and shifts
- Simple and compound assignment
- Prefix and postfix increment and decrement
- Conditional expressions
- `if` and `else`
- `while`, `do...while`, and `for`
- `break` and `continue`
- Functions and parameters
- Function calls and recursion
- Return values
- Limited `printf`
- The `print(integer)` shortcut

Supported `printf` conversions are `%d`, `%i`, `%u`, `%x`, `%X`, `%o`, `%c`, and `%%`.

Cinder is intentionally a C subset. Arrays, pointers, global variables, string variables, the preprocessor, and the standard C library are not currently implemented.

See [the language guide](docs/LANGUAGE.md) for syntax, limits, and unsupported features.

## Architecture

```text
C source
  |
  v
Lexer
  |
  v
Tokens
  |
  v
Recursive-descent parser
  |
  v
Abstract syntax tree
  |
  v
Bytecode generator
  |
  v
Bounded virtual machine
  |
  v
Output or diagnostic
```

The browser interface displays the intermediate stages produced by this pipeline.

See [the architecture guide](docs/ARCHITECTURE.md) for implementation details.

## Safety limits

Cinder executes programs inside its own virtual machine. It does not execute visitor-supplied native machine code.

| Resource | Maximum |
|---|---:|
| Source text | 32 KB |
| Tokens | 8,192 |
| Syntax-tree nodes | 8,192 |
| Bytecode instructions | 16,384 |
| Functions | 128 |
| Parameters per function | 32 |
| Local variables per function | 256 |
| VM stack | 4,096 values |
| Function-call depth | 128 |
| Execution | 200,000 instructions |
| Output | 8 KB |

The browser also enforces a three-second worker timeout.

## Requirements

Local development requires:

- GCC
- Zig
- PowerShell
- Python for the local static server
- A modern browser

Verify the compiler tools:

```powershell
gcc --version
zig version
```

## Build

Run from the repository root:

```powershell
.\scripts\build.ps1
```

The build produces:

```text
build/cinder.exe
web/cinder.wasm
```

The native compiler is built in C11 mode with warnings treated as errors.

## Test

```powershell
.\scripts\test.ps1
```

The test script always performs a clean compiler build before running the test programs.

Tests cover:

- Arithmetic
- Functions and recursion
- Control flow
- Character literals
- Compound assignment
- Prefix and postfix updates
- Bitwise operations
- Conditional expressions
- `do...while`
- Expanded formatted output
- Runtime diagnostics

## Run locally

```powershell
.\scripts\serve.ps1
```

Then open:

```text
http://localhost:4173
```

Use the local server instead of opening `index.html` directly because browsers restrict WebAssembly loading from local files.

## Browser implementation

The native compiler source is compiled to `web/cinder.wasm`.

`web/compiler-worker.js` loads the WebAssembly module and performs compilation outside the main interface thread. `web/app.js` controls the editor, result views, source navigation, timeout, rendering limits, and worker lifecycle.

Source code remains inside the visitor’s browser.
